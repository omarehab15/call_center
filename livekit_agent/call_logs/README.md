# Call Logs Documentation

## Overview
كل مكالمة (call) تنشئ ملف log منفصل يحتوي على سجل كامل وقابل للقراءة للمحادثة والملاحظات والأحداث.

## Log File Structure

### Naming Convention
```
{room_name}_{YYYYMMDD_HHMMSS}.txt
```

مثال:
```
voice_assistant_room_1234_20240604_143022.txt
```

### File Contents

#### 1. Call Header
```
================================================================================
📞 CALL LOG - voice_assistant_room_1234
================================================================================
Start Time: 2024-06-04 14:30:22
Room Name: voice_assistant_room_1234
================================================================================
```

#### 2. Call Messages
تسجيل جميع الرسائل والأحداث بصيغة منظمة:

```
[HH:MM:SS] 👤 USER: رسالة المستخدم هنا
[HH:MM:SS] 🤖 AGENT: رد الـ Agent هنا
[HH:MM:SS] 📝 NOTE: ملاحظة تم حفظها (اسم، مشكلة، إلخ)
[HH:MM:SS] ⚙️  SYSTEM: حدث نظام (مثل اتصال، قطع، إلخ)
[HH:MM:SS] ❌ ERROR: رسالة خطأ إن وجدت
```

#### 3. Call Summary
عند انتهاء المكالمة، يتم حفظ ملخص يتضمن:

```
================================================================================
📊 CALL SUMMARY
================================================================================
End Time: 2024-06-04 14:31:45
Duration: 1m 23s
Total Notes: 3

NOTES CAPTURED:
  1. اسم العميل: أحمد محمد
  2. المشكلة: رغب في إلغاء الطلب رقم 5432
  3. رقم الحساب: ACC-9876
================================================================================
```

## Features

### 1. Readable Format
- جميع الوقتات بصيغة HH:MM:SS
- رموز تعبيرية (emojis) لتمييز أنواع الرسائل
- نصوص واضحة وسهلة القراءة

### 2. Complete Conversation Tracking
- تسجيل كل رسالة من المستخدم والـ Agent
- تسجيل جميع الملاحظات المحفوظة
- تسجيل الأحداث النظامية

### 3. Call Duration
- يتم حساب مدة المكالمة تلقائياً
- تنسيق سهل الفهم (دقائق وثواني)

### 4. Notes Summary
- ملخص شامل لجميع الملاحظات المحفوظة خلال المكالمة

## Location
جميع ملفات اللوجات يتم حفظها في:
```
livekit_agent/call_logs/
```

## Example Usage

عند تشغيل الـ agent والاتصال، سيتم إنشاء ملف مثل:
```
livekit_agent/call_logs/voice_assistant_room_1234_20240604_143022.txt
```

يمكنك فتح هذا الملف مباشرة للاطلاع على سجل المكالمة كاملة.

## How It Works

1. **عند إنشاء Call جديد:**
   - يتم إنشاء كائن `CallLogger` بناءً على room name
   - يتم إنشاء ملف جديد مع header

2. **أثناء المكالمة:**
   - كل رسالة مستخدم يتم تسجيلها
   - كل ملاحظة يتم حفظها يتم تسجيلها
   - كل رسالة agent يتم تسجيلها
   - أي أحداث نظامية يتم تسجيلها

3. **عند انتهاء المكالمة:**
   - يتم حفظ ملخص المكالمة
   - يتم حفظ جميع الملاحظات
   - يتم حساب مدة المكالمة

## Integration

يتم التكامل التلقائي مع:
- `Assistant` class - يحفظ الرسائل والملاحظات
- `AgentSession` - يحفظ رسائل Agent
- `my_agent` function - يحفظ الملخص عند انتهاء المكالمة

لا تحتاج إلى أي تغييرات يدوية - كل شيء يعمل تلقائياً!
